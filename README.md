# IN1007

Solutions to tutorial exercises from the [IN1007 Programming in Java](https://curriculum.citystgeorges.ac.uk/subject/2026/IN1007) module @ [City St George's, University of London](https://www.citystgeorges.ac.uk).

## Structure / Running

Each solution is under its respective folder, e.g. `week1/`. To run one, use:

```sh
java path/to/exNumber.java
```

> [!NOTE]
> Command requires [JDK](https://openjdk.org) 11 or later installed.

[Zed](https://zed.dev) users can also use the provided [debug task](.zed/debug.json) with the [Java extension](https://zed.dev/extensions/java).
